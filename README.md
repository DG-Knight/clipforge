## ✨ ทำไมต้องเลือก ClipForge

| ความสามารถพิเศษ | สรุปใน 1 ประโยค |
|---|---|
| 🚀 **2 เส้นทางในการผลิตคลิป** | ผลิตคลิปได้ฟรี 100% (0 บาท) ด้วยฟุตเทจฟรี + เสียงพากย์ Edge TTS + ตัดต่อในเครื่อง หรือใช้โมเดล AI คุณภาพสูงพร้อมแสดงราคาก่อนเริ่มทำ |
| 🧭 **โหมดมือใหม่ / โหมดผู้กำกับ** | มือใหม่คลิกเดียวทำให้อัตโนมัติทุกขั้นตอน ส่วนผู้กำกับควบคุมสตอรี่บอร์ด โมเดล ต้นทุน และการซ่อมแซมได้เต็มที่ |
| 🧬 **ความต่อเนื่องข้ามช็อต** | รักษาอัตลักษณ์ของตัวละคร สินค้า และเฟรมเชื่อมโยงระหว่างช็อตอย่างสมจริง พร้อมเสียงพูดและเสียงบรรยากาศซิงค์สมบูรณ์ |
| 🔬 **เสียช่วงไหน ซ่อมเฉพาะช่วงนั้น** | ไม่ลบช็อตเดิมทิ้ง สามารถเลือกซ่อมเฉพาะวินาทีที่มีปัญหาตามผลตรวจ QC โดยตรวจสอบค่าใช้จ่ายก่อนยืนยัน |
| 🎬 **รวมการสร้างด้วย AI และการตัดต่อไว้ในที่เดียว** | เปลี่ยนภาพนิ่งเป็นวิดีโอเคลื่อนไหว (Image-to-Video) หรือนำเข้าคลิปจริงมาตัดต่อตามข้อความ ลบช่วงเงียบ และฝังคำบรรยายอัตโนมัติ |
| 🛡️ **ระบบป้องกันค่าใช้จ่าย** | ตรวจสอบและแสดงตัวอย่างก่อนตัดเงินจาก API กู้คืนงานที่สะดุดได้ และมีระบบ QC ตรวจสอบคลิปก่อนตัดสินใจทำใหม่ |
| 📦 **รองรับการผลิตเชิงอุตสาหกรรม** | เทมเพลตขายของกว่า 391 แบบ, ตามกระแสเทรนด์ฮิต, ถอดแบบคลิปไวรัล, ผลิตคลิป A/B หลายเวอร์ชันพร้อมกัน |
| 🚦 **ระบบตรวจสอบความปลอดภัยในตัว** | ป้ายกำกับเนื้อหา AIGC, ตรวจจับคำต้องห้ามทางโฆษณา และการตรวจสอบความพร้อมก่อนโพสต์ |
| 🤖 **เชื่อมต่อกับ AI Agent ได้โดยตรง** | ใช้งานผ่านหน้าเว็บ, MCP Server, คำสั่ง CLI หรือ Agent Skill ได้ด้วยมาตรฐานเดียวกัน |

- **[การจัดองค์ประกอบภาพและการส่งออกหลายแพลตฟอร์ม](docs/platform-framing.md)**: ล็อกเวอร์ชันวิดีโอ เลือกระหว่างพื้นหลังเบลอ ขอบดำ หรือครอบตัดเต็มจอ ปรับตำแหน่งการครอปและดูตัวอย่างภาพจริง ส่งออกตามแต่ละแพลตฟอร์ม รองรับการยกเลิกและทำซ้ำเฉพาะจุด ประมวลผลในเครื่องแบบไม่ต้องพึ่งคลาวด์ภายนอก

- 📁 **คลังสื่อในเครื่อง (v0.9.3)**: อัปโหลดรูปภาพและวิดีโอของตัวเองเป็นชุด ตรวจจับไฟล์ซ้ำ แก้ไขชื่อและแท็ก ค้นหาและดูตัวอย่าง เพื่อนำมาใส่ในแต่ละช็อตได้ทันที
- 🎞️ **สร้างคลิปทั้งเรื่องในคลิกเดียว**: คณะกรรมการตรวจสคริปต์ 4 ด้าน (จังหวะ/ภาษาพูด/ความคิดสร้างสรรค์/โครงสร้าง) ช่วยเกลาบทให้กระชับพร้อมใช้งาน; ระบบสตอรี่บอร์ด 3x3 วาด 9 ช็อตในภาพเดียวเพื่อล็อกตัวละคร ชุด แสง และฉากให้ตรงกัน 100% แล้วตัดแบ่งเป็นคีย์เฟรมแต่ละช็อต ส่งต่อให้โมเดลสร้างวิดีโอทั้งเรื่อง (≤30 วินาที) ในการเรียกใช้เพียงครั้งเดียว
- 🎬 **มุมกล้องเคลื่อนไหวสมจริง**: เทคนิค Image-to-Video พร้อมการเปลี่ยนฉากแบบไร้รอยต่อ มีพรีเซ็ตมุมกล้องให้เลือก 18 แบบ (เช่น ซูมเข้า หมุนรอบ เลื่อนตาม) สามารถผสม 2 มุมกล้องเข้าด้วยกัน และมีโทนภาพสำเร็จรูป 8 สไตล์
- 🧭 **พื้นที่ทำงาน 2 โหมด**: แถบนำทางด้านข้างเข้าถึงทุกหน้าได้อย่างรวดเร็ว พร้อมปุ่มสลับระหว่าง «โหมดมือใหม่ ⇄ โหมดผู้กำกับ» โหมดมือใหม่จัดการให้อัตโนมัติตั้งแต่เขียนบท นำฟุตเทจฟรีมาประกบ ใส่เสียงพากย์ฟรี จนถึงหน้าวิดีโอสำเร็จรูป ส่วนโหมดผู้กำกับจะเปิดแผงควบคุมสตอรี่บอร์ด มุมกล้อง และการปรับแต่งระดับสูง
- 🧠 **ระบบผลิตอัจฉริยะ (v0.8.93)**: แสดงสถานะการทำงาน 9 ขั้นตอน ค่าใช้จ่ายจริงของโมเดล การประเมินเวลา และการแนะนำโมเดลที่คุ้มค่าที่สุด มีระบบบันทึกความตั้งใจในการสร้างสรรค์ (Visual Bible) ช่วยคุมโทนภาพ แสง สี เสื้อผ้าข้ามช็อตอย่างแม่นยำ
- 🔬 **ประตูกั้นคุณภาพของช็อต (v0.8.98)**: เก็บทุกเทคที่สร้างขึ้นมาเพื่อให้เปรียบเทียบ ตรวจสอบความถูกต้องของภาพ การขยับไหว ความต่อเนื่อง และการแสดงผลตัวอักษร มีเพียงเวอร์ชันที่คุณกดยอมรับเท่านั้นที่จะถูกนำไปเรนเดอร์ในวิดีโอตัวเต็ม
- 🩺 **ซ่อมแซมช็อตอย่างแม่นยำ (v0.9.0)**: เมื่อพบจุดบกพร่อง ระบบจะระบุช่วงเวลาที่ต้องแก้ไข และสร้างเฉพาะช่วงสั้นๆ นั้นใหม่ โดยนำมาประกอบเข้ากับฟุตเทจเดิมและรักษาเสียงต้นฉบับไว้ ไม่ต้องจ่ายเงินทำใหม่ทั้งคลิป
- 🎚️ **ความต่อเนื่องของภาพและปรับมาสเตอร์ริ่ง (v0.9.1)**: ตรวจวัดความสว่าง สี และความอิ่มตัวของสี ณ จุดรอยต่อของแต่ละฉาก พร้อมปรับระดับความดังของเสียง (Loudness) ตามมาตรฐาน EBU R128 ให้สม่ำเสมอตลอดทั้งคลิป

## 🧩 โครงการอื่นจากผู้พัฒนา

## 🚀 เริ่มต้นใช้งานใน 30 วินาที

```bash
docker run -d -p 3000:3000 -v clipforge-data:/data ghcr.io/xixihhhh/clipforge
```

## 🎬 รูปแบบการใช้งานหลัก 2 สไตล์

- **🛍️ วิดีโอขายสินค้าอีคอมเมิร์ซ (งานหลัก)**: **อัปโหลดรูปสินค้า หรือวางลิงก์หน้าสินค้า** (ระบบจะดึงรูป ชื่อ และราคาให้อัตโนมัติ) → AI สกัดจุดขายและเขียนสคริปต์ปิดการขาย → วิดีโอแสดงสินค้าจริงที่คมชัดไม่บิดเบี้ยว + สลับฟุตเทจการใช้งานฟรี → ใส่เสียงพากย์ คำบรรยาย ดนตรีประกอบ → ส่งออกคลิปขนาด 9:16 หรือ 3:4 ได้ในคลิกเดียว
- **🗣️ วิดีโอจากหัวข้อประโยคเดียว**: แม้ไม่มีสินค้าก็ทำคลิปได้ — พิมพ์หัวข้อที่ต้องการ (เช่น «วิธีชงกาแฟดริปให้อร่อยที่บ้าน») → AI เขียนบทบรรยาย → นำเข้าฟุตเทจคุณภาพสูงที่เกี่ยวข้องฟรี → ใส่เสียงพากย์ภาษาไทยและคำบรรยาย → ได้คลิปวิดีโอสั้นพร้อมโพสต์

## 💡 ขั้นตอนจริง: รูปสินค้า 1 รูป → คลิปพร้อมขายใน 30 วินาที

1. **อัปโหลดรูปและระบุชื่อ** — ใส่รูปสินค้าและระบุชื่อสินค้า เลือกแพลตฟอร์มที่ต้องการลง (TikTok / Reels / Shorts / Shopee)
2. **AI ร่างสคริปต์ (~30 วินาที)** — ได้สคริปต์ปิดการขาย 3 แบบ (ชี้จุดเจ็บปวด / จำลองสถานการณ์ / เปรียบเทียบผลลัพธ์) พร้อมท่อนฮุก 3 วินาทีทอง แฮชแท็ก และข้อความหน้าปก
3. **จัดเตรียมภาพ** — แสดงรูปสินค้าจริงของคุณอย่างชัดเจน ผสมผสานกับคลังฟุตเทจภาพไลฟ์สไตล์ฟรี
4. **ตัดต่อและสังเคราะห์อัตโนมัติ** — ใส่เสียงพากย์ AI + ฝังคำบรรยายภาษาไทย + ป้ายราคา + ดนตรีประกอบ ประมวลผลผ่าน FFmpeg ภายในเครื่อง
5. **ดาวน์โหลดและโพสต์** — นำคลิปไปโพสต์ลงช่องทางขายของคุณได้ทันที

## ❓ คำถามที่พบบ่อย (FAQ)

**ClipForge คืออะไร?**  
ClipForge คือเครื่องมือสร้างวิดีโอสั้นขายของและคอนเทนต์ด้วย AI แบบโอเพนซอร์ส เพียงอัปโหลดรูปสินค้า 1 รูป ระบบจะช่วยวิเคราะห์จุดขาย เขียนบท รักษารูปทรงสินค้าจริง นำเข้าฟุตเทจและเสียงพากย์ภาษาไทย พร้อมใส่คำบรรยายให้อัตโนมัติ

**ใช้งานฟรีจริงไหม? จำเป็นต้องมี API Key หรือไม่?**  
สามารถใช้งานได้ **ฟรี 100% โดยไม่ต้องมี API Key** ระบบมีตัวเลือกใช้ฟุตเทจฟรี (จาก Openverse และ Wikimedia), เสียงพากย์ฟรีจาก Microsoft Edge TTS (มีเสียงภาษาไทย เปรมวดี และ นิวัฒน์), และประมวลผลตัดต่อด้วย FFmpeg ในเครื่องของคุณเอง คุณจะเสียค่าใช้จ่ายเฉพาะเมื่อต้องการเชื่อมต่อกับโมเดล AI พิเศษภายนอกเท่านั้น

**มีลายน้ำไหม และสามารถใช้ในเชิงพาณิชย์ได้หรือไม่?**  
**ไม่มีลายน้ำใดๆ ทั้งสิ้น** เป็นโปรเจกต์โอเพนซอร์ส (สัญญาอนุญาต AGPL-3.0) คุณสามารถนำผลงานวิดีโอที่เรนเดอร์ออกมาไปใช้ในเชิงพาณิชย์ โพสต์ขายสินค้า หรือยิงโฆษณาได้ทันที

**แตกต่างจาก CapCut หรือโปรแกรม AI เจ้าอื่นอย่างไร?**  
ClipForge เป็นโอเพนซอร์ส รันในเครื่องของคุณ ข้อมูลสินค้าและวิดีโอไม่รั่วไหลไปคลาวด์ภายนอก ไม่มีค่าบริการรายเดือนสำหรับฟังก์ชันพื้นฐาน และไม่มีลายน้ำติดในวิดีโอ

**ทำคลิปไม่เป็น ไม่เคยตัดต่อ จะใช้ได้ไหม?**  
ใช้งานได้แน่นอน เพราะกระบวนการทั้งหมดทำงานอัตโนมัติ คุณเพียงเลือกรูปและพิมพ์ชื่อสินค้า ไม่จำเป็นต้องออกกล้อง ไม่ต้องมีทักษะการถ่ายทำ หรือการใช้โปรแกรมตัดต่อที่ซับซ้อน

**รองรับภาษาไทยหรือไม่?**  
รองรับภาษาไทยเต็มรูปแบบ 100% ทั้งหน้าจอเมนูทั้งหมด, สคริปต์, เสียงพากย์ภาษาไทย, และระบบคำบรรยายภาษาไทยที่มีระบบตัดคำอัตโนมัติอย่างสวยงาม

## 🛠️ รายละเอียดฟีเจอร์เด่น (Core Features)

### 1. ระบบเขียนสคริปต์ขายของด้วย AI
- แม่แบบเฉพาะทาง 5 หมวดหมู่: ความงามและสกินแคร์ / อาหารและขนม / ของใช้ในบ้าน / แฟชั่นเสื้อผ้า / อุปกรณ์ไอทีและดิจิทัล
- สไตล์บทพูด 10 รูปแบบ: ละครสั้นหักมุม, บทสัมภาษณ์, รีวิวแกะกล่อง, เล่าเรื่องจากปัญหาของผู้ใช้ ฯลฯ
- คลังท่อนฮุก 3 วินาทีแรก: ภาพเปิดสะดุดตา, คำถามกระตุ้นความสงสัย, การเปรียบเทียบชัดเจน, สัญญาถึงประโยชน์ที่จะได้รับ
- ปรับแต่ง SEO ให้เข้ากับอัลกอริทึมของ TikTok, Reels, Shorts, Shopee

### 2. ผลิตสื่อด้วย AI หลายโมเดล (Multi-Model Aggregation)
- รองรับการเปลี่ยนภาพนิ่งเป็นวิดีโอเคลื่อนไหว (Image-to-Video) คุณภาพสูงโดยที่รูปทรงสินค้าไม่บิดเบี้ยว
- เชื่อมต่อกับผู้ให้บริการชั้นนำ: **Atlas Cloud**, **fal.ai**, **Replicate**, **Volcengine (Ark)**, **Alibaba Bailian**, **OpenAI**
- รองรับโมเดลวิดีโอยอดนิยม: Seedance 2.5, MiniMax H3, Kling O3, Veo 3.1, Wan 2.7 ฯลฯ

### 3. คลังฟุตเทจและดนตรีประกอบฟรีในตัว
- ดึงรูปภาพ วิดีโอ และเสียงเอฟเฟกต์จากแหล่งสัญญาอนุญาตเชิงพาณิชย์ฟรี: **Openverse**, **Wikimedia Commons**, **Coverr**, **Jamendo**, **Freesound**
- รองรับการนำเข้าฟุตเทจส่วนตัวในเครื่องเข้ามาใช้งานร่วมกัน

### 4. เอนจินตัดต่อวิดีโอประสิทธิภาพสูง (FFmpeg Compositing)
- เข้ารหัสวิดีโอคุณภาพสูงระดับมืออาชีพ H.264 High Profile, AAC คมชัด
- **ระบบคำบรรยายภาษาไทยอัจฉริยะ**: ตัดคำภาษาไทยตามพจนานุกรม สระบน-ล่างและวรรณยุกต์ไม่กระโดดลอยหรือขึ้นต้นบรรทัดใหม่อย่างผิดไวยากรณ์
- รองรับสไตล์ซับไตเติลหลายแบบ ทั้งแบบกล่องข้อความ, แบบตัวหนาเน้นข้อความ, และแบบคาราโอเกะที่ไฮไลต์ตามจังหวะเสียงพูด
- ผสมผสานเสียงพากย์และดนตรีประกอบพร้อมระบบลดเสียงเพลงอัตโนมัติขณะมีเสียงพูด (Audio Ducking)

## 💻 การติดตั้งและพัฒนาในเครื่อง (Local Setup)

### ติดตั้งผ่าน Docker (แนะนำและรวดเร็วที่สุด)
```bash
docker run -d -p 3000:3000 -v clipforge-data:/data ghcr.io/xixihhhh/clipforge
```

### การรันเพื่อพัฒนา (Local Development)
โปรเจกต์นี้ใช้ **pnpm** ในการจัดการแพ็กเกจ:

```bash
# โคลนคลังโค้ด
git clone https://github.com/xixihhhh/clipforge.git
cd clipforge

# ติดตั้ง dependencies
pnpm install

# รันเซิร์ฟเวอร์สำหรับการพัฒนา
pnpm dev

# เปิดเบราว์เซอร์
# เข้าไปที่ http://localhost:3000
```

### คำสั่งที่มีประโยชน์ในการพัฒนา
```bash
# รันชุดทดสอบอัตโนมัติ
pnpm test

# ตรวจสอบรูปแบบโค้ด (Lint)
pnpm lint

# สร้างเวอร์ชัน Production
pnpm build
```

## 🏗️ สถาปัตยกรรมทางเทคนิค (Tech Stack)

- **Frontend**: Next.js 16 (App Router) + React 19 + Tailwind CSS 4 + shadcn/ui
- **State Management**: Zustand (จัดเก็บสถานะลงในหน่วยความจำและ LocalStorage)
- **Database**: SQLite + Drizzle ORM (ไมเกรตฐานข้อมูลอัตโนมัติเมื่อเริ่มระบบ)
- **Video Engine**: FFmpeg (ประมวลผลตัดต่อ แปลงไฟล์ และฝังซับไตเติล)
- **Testing**: Vitest (ครอบคลุมทั้ง Unit Test และ Integration Test)
- **Desktop App**: รองรับการแพ็กเกจเป็นแอปเดสก์ท็อปผ่าน Electron
