# แผนงานการเพิ่มการรองรับภาษาไทยใน ClipForge (Thai Language Support Implementation Plan)

## 1. วัตถุประสงค์
พัฒนาโปรเจกต์ ClipForge จากเดิมที่รองรับเฉพาะภาษาจีน (zh) และภาษาอังกฤษ (en) ให้รองรับ **ภาษาไทย (th)** อย่างสมบูรณ์และถูกต้องตามมาตรฐาน โดยครอบคลุมทั้ง:
1. ระบบข้อความหน้าจอและส่วนติดต่อผู้ใช้ (UI Localization / i18n)
2. ตัวเลือกภาษาในตัวสลับภาษา (Language Switcher) และการตรวจจับภาษาของเบราว์เซอร์อัตโนมัติ (Browser Locale Detection)
3. ระบบเสียงบรรยายและพากย์เสียงภาษาไทย (Thai Text-to-Speech / Edge TTS voices)
4. การเรนเดอร์คำบรรยายใต้ภาพและซับไตเติลภาษาไทย (Thai Subtitles Rendering & Font Fallback)
5. การทดสอบอัตโนมัติ (Automated Tests) เพื่อยืนยันความถูกต้อง ครบถ้วนของคีย์คำแปล และไม่มีข้อผิดพลาด

## 2. ขอบเขตงาน (Scope of Work)

### ส่วนที่ 1: โครงสร้างหลักของระบบ i18n
- **`src/lib/i18n/config.ts`**:
  - เพิ่ม `"th"` ลงใน `LOCALES`
  - เพิ่ม `th: "ไทย"` ใน `LOCALE_LABELS`
  - ปรับปรุงประเภท `NamespaceMessages` ให้มีฟิลด์ `th: Record<string, string>`
  - ปรับปรุง `detectBrowserLocale()` ให้ตรวจจับรหัสภาษา `th` (หรือ `th-TH`) และตั้งค่าภาษาเริ่มต้นเป็นภาษาไทยสำหรับผู้ใช้ในไทย
- **`src/lib/i18n/messages/index.ts`**:
  - ผูกข้อความภาษาไทย `th` เข้ากับระบบรวมทุก Namespace

### ส่วนที่ 2: ข้อความคำแปลภาษาไทย (Localization Messages)
แปลและเพิ่มชุดข้อความภาษาไทย `th: { ... }` ในไฟล์ทั้งหมด 21 โมดูลใน `src/lib/i18n/messages/`:
1. `common.ts` - เมนูนำทาง, ปุ่มกดหลัก, สถานะงาน, หน้าต่างแจ้งเตือน
2. `home.ts` - หน้าแดชบอร์ดหลัก, เมนูฟังก์ชันด่วน, สถิติ
3. `start.ts` - หน้าเริ่มต้นโปรเจกต์ใหม่, ตัวเลือกการนำเข้า
4. `topic.ts` - การเลือกหัวข้อ, การสร้างไอเดีย, แท็ก
5. `newProject.ts` - ตัวช่วยสร้างโปรเจกต์, การตั้งค่าอัตราส่วนภาพ
6. `clone.ts` - การคัดลอก/ถอดแบบวิดีโอยอดนิยม (Hit Video Replication)
7. `batch.ts` - การผลิตวิดีโอแบบกลุ่ม (Batch Production)
8. `products.ts` - คลังสินค้า, การจัดการข้อมูลสินค้าสำหรับคลิปขายของ
9. `settings.ts` - การตั้งค่าระบบ, API ผู้ให้บริการ, ผู้ให้บริการเสียงและโมเดล AI
10. `generationSettings.ts` - การตั้งค่าพารามิเตอร์การสร้างวิดีโอ
11. `showcase.ts` - หน้ารวมตัวอย่างผลงาน
12. `script.ts` - เอดิเตอร์แก้ไขสคริปต์, การตรวจสคริปต์, สไตล์การเล่าเรื่อง
13. `assets.ts` - การจัดการภาพ ฟุตเทจ เสียงดนตรีประกอบ (BGM)
14. `video.ts` - หน้าพรีวิววิดีโอ, ไทม์ไลน์, การปรับแต่งภาพ
15. `exportPage.ts` - การส่งออกวิดีโอ, ความละเอียด, การดาวน์โหลด, บันทึกการส่งออก
16. `projectsPage.ts` - หน้ารายการโปรเจกต์ทั้งหมด, การค้นหาและกรอง
17. `presenters.ts` - คลังผู้บรรยายและผู้ประกาศดิจิทัล
18. `mediaLab.ts` - ห้องทดลองสื่อ, การแยกองค์ประกอบวิดีโอ
19. `production.ts` - ระบบการผลิตวิดีโออัตโนมัติ (Production Pipeline)
20. `transcript.ts` - การแก้ไขวิดีโอด้วยข้อความบรรยาย (Text-based Video Editing)
21. `materials.ts` - คลังวัตถุดิบและสื่อในเครื่อง

### ส่วนที่ 3: ระบบเสียงพากย์ภาษาไทย (Thai Text-To-Speech)
- อัปเดต `src/lib/tts-voices.ts`:
  - เพิ่มเสียงภาษาไทยฟรีสำหรับ Edge TTS ได้แก่:
    - `th-TH-PremwadeeNeural` (เปรมวดี · หญิง)
    - `th-TH-NiwatNeural` (นิวัฒน์ · ชาย)
  - เพิ่มการรองรับการจัดหมวดหมู่เสียงภาษาไทย

### ส่วนที่ 4: การเรนเดอร์คำบรรยาย (Subtitles & Font Support)
- ตรวจสอบการเลือกฟอนต์และการเรนเดอร์ฟอนต์ภาษาไทย เพื่อไม่ให้ตัวหนังสือภาษาไทยแสดงเป็นกล่องสี่เหลี่ยม (Tofu)

### ส่วนที่ 5: การทดสอบอัตโนมัติและการยืนยันผล (Automated Testing & Verification)
- สร้างและปรับปรุงชุดทดสอบ Vitest ใน `src/lib/__tests__/i18n-thai.test.ts`
- ตรวจสอบว่าคีย์ทั้งหมดในภาษาจีนและภาษาอังกฤษ มีในภาษาไทยครบ 100%
- ตรวจสอบว่าไม่มีค่าว่าง และการแทนที่ตัวแปร `{var}` ใช้งานได้ถูกต้อง
