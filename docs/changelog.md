# บันทึกการเปลี่ยนแปลง (Changelog)

## [v0.9.14] - 2026-10-01

### Fixed (แก้ไขจุดบกพร่องหลบซ่อนและปรับปรุงการทำคลิปขายสินค้าสำหรับคนไทย)
- **ระบบ Prompt & Script Engine ภาษาไทยสำหรับตลาด E-Commerce ไทย**:
  - แก้ไขปัญหาโมเดล AI หลุดสร้างสคริปต์เป็นภาษาอังกฤษหรือจีน เมื่อผู้ใช้ป้อนชื่อแบรนด์หรือสินค้าเป็นภาษาอังกฤษ (เช่น Dyson, Sony, Apple) หรือนำเข้าข้อมูลสินค้าจีนจาก 1688
  - เพิ่มฟิลด์ `locale` ใน `ScriptGenerationInput` และ `TopicScriptInput` พร้อมส่งต่อ `locale` จากทุกหน้าของ UI (`/start`, `/project/[id]/script`, `/project/new`, `/project/clone`, `/project/topic`, `/batch`)
  - กำหนดคำสั่งเฉพาะภาษาไทยใน Prompt: บังคับแต่งบทพากย์เป็นภาษาไทยธรรมชาติสำหรับแพลตฟอร์มยอดนิยมของไทย (TikTok Shop TH, Shopee TH, Reels TH)
  - เพิ่มจังหวะความเร็วการพูดภาษาไทยที่เหมาะสม (10-14 ตัวอักษร/วินาที หรือ 3-4 คำ/วินาที) ป้องกันปัญหาสคริปต์สั้นเกินไปจนเกิดช่วงเงียบในวิดีโอ
  - เพิ่มการบังคับคำลงท้ายสุภาพ (ครับ/ค่ะ), Hook เปิดคลิปดึงดูดใจ และ Call-to-Action ปิดการขายสไตล์ไทย (เช่น "กดในตะกร้าสีเหลืองด้านล่างได้เลยครับ", "มีบริการเก็บเงินปลายทาง")
- **ระบบเสียงพากย์ดีฟอลต์ไทยใน API Edge TTS**:
  - ปรับปรุง `/api/tts/free` ให้ตรวจจับภาษาและเลือกใช้เสียงไทยเปรมวดี (`th-TH-PremwadeeNeural`) เป็นค่าเริ่มต้นเมื่อพรีวิวเสียงพากย์หรือทดสอบเสียงไทย แทนที่จะหลุดเป็นเสียงจีน Xiaoxiao
  - ปรับปรุง `pickLocale` ใน `src/lib/api-error.ts` ให้คืนค่า `th` เป็นค่าเริ่มต้น
- **ระบบค้นหาฟุตเทจวิดีโอสต็อกฟรี (Smart Stock Matcher)**:
  - เพิ่มฟังก์ชัน Smart Latin Token Extraction ใน `broadenQuery` ของ `src/lib/stock-matcher.ts`
  - หากชื่อหรือคำอธิบายสินค้ามีชื่อแบรนด์หรือรุ่นเป็นภาษาอังกฤษผสมอยู่ (เช่น "หูฟัง Sony WH-1000XM5 ตัดเสียงรบกวน") ระบบจะดึงคำค้นอังกฤษไปค้นหาคลิปวิดีโอจาก Pexels/Pixabay ได้อย่างตรงจุด แทนที่จะตกไปที่วิดีโอพื้นหลังทั่วไป (abstract background)
- **ชุดทดสอบอัตโนมัติ (Automated Tests)**:
  - เพิ่มไฟล์ทดสอบ `src/lib/__tests__/thai-systematic-pipeline.test.ts` ครอบคลุมการทำงานทั้ง 7 เคสสำคัญ และอัปเดต `stock-matcher.test.ts` ผ่าน 100%

## [v0.9.13] - 2026-10-01

### Fixed (แก้ไขสัญลักษณ์สกุลเงินและการตั้งค่า AI)
- **สัญลักษณ์สกุลเงินบาท (฿) ในหน้า UI**:
  - แก้ไขปุ่มตัวอย่างสินค้าในหน้าหลัก (`/start`) และหน้าสร้างโปรเจกต์ (`/project/new`) ที่เคยมีสัญลักษณ์เงินหยวน `¥` ฝังอยู่ในโค้ด ให้เปลี่ยนเป็นสัญลักษณ์ตามภาษาอัตโนมัติ (ภาษาไทยแสดง `฿`, ภาษาอังกฤษแสดง `$`, ภาษาจีนแสดง `¥`)
  - เพิ่มฟังก์ชัน `currencySymbolForLocale()` ใน `src/lib/examples.ts`
  - รองรับสกุลเงินบาท THB (`฿`) ในระบบสกัดข้อมูลสินค้าจากลิงก์ (`src/lib/product-ingest.ts`)
- **ปรับปรุงหน้าจอการตั้งค่า AI (Settings Page UX)**:
  - แก้ไขกล่อง Atlas One-Key ให้จดจำและแสดงคีย์ที่บันทึกไว้ในเครื่องทันที พร้อมแสดงสถานะ `✓ ใช้งานเรียบร้อยแล้ว` ไม่เด้งกลับเป็นช่องว่างเปล่า
  - ปรับปรุงให้สวิตช์ Toggle ของแพลตฟอร์ม AI และ TTS เปิดใช้งานอัตโนมัติทันทีที่มีการวางหรือพิมพ์ API Key
  - เพิ่มแถบสถานะบันทึกอัตโนมัติ (Auto-saved) ที่หัวหน้าต่างการตั้งค่า
- **จัดทำคู่มือการติดตั้งและการรันระบบ (Setup & Run Guide)**:
  - เพิ่มไฟล์ `HOW_TO_RUN.md` รวบรวมคำแนะนำการติดตั้ง, การรันโหมด Dev (`pnpm dev`), โหมด Desktop (`pnpm electron`), การบิลด์ตัวติดตั้ง `.exe` (`pnpm dist`) และวิธีแก้ปัญหาเบื้องต้นเป็นภาษาไทยสำหรับผู้ใช้ทั่วไป
  - เชื่อมโยงคู่มือ `HOW_TO_RUN.md` เข้ากับส่วนบนสุดของ `README.md` เพื่อให้เข้าถึงได้สะดวกทันที

## [v0.9.12] - 2026-09-30

### Fixed (แก้ไขจุดบกพร่องแกนกลางการสร้างวิดีโอภาษาไทย)
- **ระบบเลือกเสียงพากย์อัตโนมัติตามภาษา (Default Voice Auto-resolution)**:
  - แก้ไขปัญหาเสียงพากย์ดีฟอลต์ติดค้างเป็นภาษาจีน (`zh-CN-XiaoxiaoNeural`)
  - เพิ่มฟังก์ชัน `defaultVoiceForLang` และ `defaultVoiceForText` ใน `src/lib/tts-voices.ts` และ re-export ใน `src/lib/edge-tts.ts`
  - หากสคริปต์วิดีโอเป็นภาษาไทย ระบบจะสลับเป็นเสียง `th-TH-PremwadeeNeural` (เสียงเปรมวดี) อัตโนมัติในฝั่งเซิร์ฟเวอร์และหน้าเลือกเสียง
- **กรรมการ AI ตรวจประเมินสคริปต์ (Script Judge Thai Support)**:
  - แก้ไข `src/lib/script-judge.ts` ให้ตรวจจับสคริปต์ภาษาไทย (`hasThai`) และสั่งให้ AI ส่งผลการตัดสินและการเขียนบทใหม่เป็นภาษาไทยที่เป็นธรรมชาติ ไม่บังคับแก้เป็นภาษาอังกฤษ
- **ปกป้องคำลงท้ายสุภาพภาษาไทย (Polite Particles Preservation)**:
  - ลบคำว่า `"ครับ", "ค่ะ", "คะ"` ออกจาก `FILLER_WORDS` ใน `src/lib/transcript-editor.ts`
  - ป้องกันไม่ให้ระบบตัดทิ้งคำสุภาพที่จำเป็นต่อความน่าเชื่อถือและความเป็นธรรมชาติของคลิปขายสินค้า
- **การเรนเดอร์ภาพหน้าปก (Cover) และการ์ดสรุป (Carousel)**:
  - แก้ไข `src/lib/video-composer/cover.ts` และ `src/lib/video-composer/carousel.ts` ให้เรียกใช้ `resolveFontFileForText()`
  - สลับใช้ฟอนต์ `NotoSansThai-Regular.ttf` โดยอัตโนมัติเมื่อข้อความเป็นภาษาไทย ป้องกันตัวอักษรไทยหายหรือเป็นสี่เหลี่ยม
- **ระบบแบ่งท่อนคำบรรยายการ์ดสั้นภาษาไทย (Caption Chunking)**:
  - ปรับปรุงฟังก์ชัน `chunkCaption` ใน `src/lib/video-composer/composer.ts` โดยใช้ `Intl.Segmenter` ภาษาไทย
  - ตัดท่อนประโยคยาวให้เป็นท่อนสั้นตามขอบเขตคำ ไม่ตัดขาดกลางคำ
- **ระบบซับไตเติลคาราโอเกะและสกุลเงินบาท (Karaoke & Currency Preservation)**:
  - ปรับปรุง `src/lib/video-composer/karaoke.ts` (`splitThaiWords` และ `splitKaraokeUnits`) ให้คงสัญลักษณ์ทางการเงิน เช่น เครื่องหมายบาท `฿` และเปอร์เซ็นต์ `%` เชื่อมโยงกับคำภาษาไทยอย่างสมบูรณ์
- **ข้อจำกัดความสมจริงสินค้าในพรอมต์ภาพ AI (Realistic Product Delimiters)**:
  - แก้ไข `src/app/project/[id]/assets/page.tsx` ไม่ให้ใส่ข้อความกำกับภาษาจีน `"保持商品主体一致"` เมื่อสคริปต์เป็นภาษาไทยหรือภาษาอังกฤษ
